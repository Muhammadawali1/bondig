# Screenshots Folder

Folder ini berisi screenshot aplikasi Sistem Manajemen Bon Barang.

## Cara Menambahkan Screenshot:

1. **Ambil screenshot aplikasi** (bisa pake Snipping Tool, Lightshot, atau Greenshot)
2. **Simpan dengan nama yang jelas:**
   - `dashboard.png` - Dashboard utama
   - `request-form.png` - Form pengajuan barang
   - `approval.png` - Halaman approval
   - `reports.png` - Laporan & analytics
   - `login.png` - Halaman login
   - `inventory.png` - Manajemen stok barang

3. **Format yang direkomendasikan:**
   - Format: PNG atau JPG
   - Ukuran: Max 2MB per file
   - Resolusi: 1920x1080 atau 1366x768

4. **Tips untuk screenshot yang bagus:**
   - Pastikan browser dalam mode fullscreen
   - Hide bookmarks kalau perlu
   - Fokus ke fitur yang ingin ditampilkan
   - Jangan include data sensitif (password, email asli)
